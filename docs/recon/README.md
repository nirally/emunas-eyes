# Recon

What was found about the game while building the mod: how its camera, rendering, TAA, clock, UI and Faith's skinned body work.

Published here:
- The write-ups: `STAGE2-RECON.md` (camera and view builder), `STAGE7-RECON.md` (Faith's bone matrices), `STAGE7D-RECON.md` (her fingers), `stage8/STAGE8-RECON.md` (HUD and menus) and `taa/README.md` (TAA and the per-view constants).
- The screenshots they and the decisions log refer to.

Not published: the raw captures (frame traces, constant-buffer and bone-matrix recordings, session logs) and the code dumps of the game's executable. The dumps are EA's code, and the rest is large and only useful together with them.
References to them in `docs/DECISIONS.md`, `docs/BUGS.md` and the playtest notes (`*.txt`, `*.bin`, `*.asm`, `time/`) are kept as a record, and each finding is written up in those notes or in the files above.
