# PLAYTEST-10f: a second person installs from the zip (~20 min, optional)

For someone other than the developer, ideally on their own PC. Needs: Mirror's Edge Catalyst on Steam, SteamVR, a VR headset with controllers. Give them out/EmunasEyes-0.1.0.zip and nothing else. Stop at once if you feel warm, sweaty or dizzy.

1. Unzip it anywhere and double-click Install.bat. Did it find the game and install without help? (If not: what did it say?)
2. Start SteamVR, then the game from Steam. Do you see the game in 3D in the headset, with Faith's hands on your controllers?
3. Using only the README: could you work out moving, turning, jumping, punching and the settings menu (both sticks clicked in, held 1 s)?
4. Play ~15 minutes. Anything broken, confusing or uncomfortable? Hold Y + B if something looks wrong.
5. Double-click Uninstall.bat. Does the game start normally (flat, no VR) afterwards?
6. Which headset and controllers, and comfort 1-5 (5 = very comfortable)?

Please send back the answers and the file mecvr\mecvr.log from the game folder - copy it before step 5, the uninstall removes it.

Reply example: "1 yes, 2 yes, 3 yes, 4 nothing, 5 yes, 6 Quest 3 with Touch, 5".
