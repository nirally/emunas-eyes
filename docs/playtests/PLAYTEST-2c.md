# PLAYTEST-2c — sharper picture with DSR (~15 min, incl. 3 min setup)

Why: the headset gets exactly the picture the game draws at its screen resolution (now 1920x1080 stretched over ~129x100°). NVIDIA DSR lets the game draw at a higher resolution on a 1080p monitor; the mod now follows the resolution automatically.

Setup (desktop, once):
1. Right-click desktop -> NVIDIA Control Panel -> Manage 3D settings -> Global Settings -> "DSR - Factors": tick 1.78x and 2.25x -> OK -> Apply. (Leave "DSR - Smoothness" as it is.)
2. Start the game. Options -> Video: Display mode Fullscreen, Resolution 2560x1440. Keep Anti-aliasing and Motion blur off.

In the headset:
1. Sharpness at 2560x1440, 1-5 (read a distant sign). Is it smooth (no stutter)?
2. Options -> Video -> Resolution 2880x1620. Sharpness 1-5? Still smooth?
3. If 2880x1620 was smooth, also try 3840x2160 (needs 4.00x ticked in step 1 of setup) - optional.
4. Anything wrong after changing resolution (black eye, frozen picture, wrong colours)?
5. Comfort 1-5: nausea / eye strain.

Leave the game at the best resolution that stayed smooth. To undo: set the game back to 1920x1080 (DSR in the control panel does nothing on its own).
Reply example: "1440: 4 smooth, 1620: 4 slight stutter, 4 nothing, 5 1/1".
