# PLAYTEST-2e — eye sync, body flicker fixed (~10 min)

3. Shift+F4 off and on once: better with sync on, off, or the same?
4. Anything new (stutter, frozen eye, wrong speed)?
5. Comfort 1-5: nausea / eye strain.
