# RECON-1 — Find the gameplay camera (no headset, ~5 minutes)

This isn't a gate test. It's a data-gathering session only you can do, because it needs gameplay.
The mod is installed with recon tools switched on. Nothing changes in normal play until you press F8 or F9.

How to launch: Steam → Play. If nothing happens within a minute, click Play again.
How to quit safely: quit from the game's menu.

| # | Do this | What you'll see |
|---|---|---|
| 1 | Load your save. Stand somewhere quiet, no enemies around | Normal game |
| 2 | Press **Esc** to pause. Wait 5 seconds | Pause menu |
| 3 | Press **F8**. Don't touch anything for about **90 seconds** | The background view may **jump up briefly** a few times. That's the mod testing which memory moves the camera. Expected |
| 4 | Unpause (Esc). Walk around and look around with the mouse continuously, and press **F9** while moving. Keep moving ~10 more seconds | Normal game |
| 5 | Do one wall-run or jump, press **F9** mid-move | Normal game |
| 6 | Quit from the menu | |

If the game crashes during step 3, that's useful data too. Relaunch and tell me.
Reply "done" plus anything odd.
