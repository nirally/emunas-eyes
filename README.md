# Mirror's Edge Catalyst VR

A full 6DoF motion-controller VR conversion of Mirror's Edge Catalyst (Steam, v1.0.3.47248), in development.

**Status:** pre-alpha. Nothing playable yet. See `docs/PHASE_PLAN.md`.

- Single-player/offline only. Does not modify or bypass the game's DRM.
- Ships only its own files. No game assets or executables are redistributed.
- Uninstall: delete the mod's files, then use Steam → *Verify integrity of game files*.

Project docs live in `docs/`. Game-specific data lives in `config/manifest.json`.
